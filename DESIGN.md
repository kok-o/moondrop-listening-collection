# MOONDROP / Listening collection

Некоммерческая авторская витрина. Основной мотив — переход от рисунка к физическому объекту: официальный цветной эскиз Mitsuki Yuki в COSMO и фотография тех же наушников. Это связывает художественную часть именно с MOONDROP, а не с произвольной аниме-эстетикой.

## Система

- Молочный #F7F6F2, белый #FCFCFD, графит #252628, пыльная роза #CE9EAA, серебро #DADDE0, тёмный #171A1E.
- Manrope: русский интерфейс, заголовки и текст. Oswald: латинское MOONDROP и названия моделей. Шрифты локальные, с кириллицей, Google Fonts / OFL.
- Сетка: поля 22 / 32 / 5vw, асимметричная пара карточек и отдельная горизонтальная сцена COSMO.
- Масштаб текста: основные заголовки 39–82 px; продуктовые заголовки 35–70 px; подписи меньше основного текста, спецификации сгруппированы.
- Основной цикл: первый экран → закреплённая смена акцента с Yuki на COSMO → коллекция → тишина и звуковые линии → сравнение → официальные страницы.

## Проверка направления до реализации

Отказ от случайного цветного маскота в пользу официального рисунка COSMO. Три модели разделены по реальным сценариям: беспроводные SPACE TRAVEL, гибридные внутриканальные DUSK, полноразмерные COSMO. Не используется вымышленная музыкальная частотная характеристика: декоративная волна — авторская графика, а синтезированный эмбиент явно обозначен как атмосфера, не демонстрация звучания устройств.

## Движение

- Вступление: один каскад CSS transform/opacity, 850–1100 мс; знак бренда не анимируется.
- Пространственная связь: GSAP ScrollTrigger, sticky-сцена 185svh, скраб перемещения продукта и удаления персонажа. React не перерисовывается на кадрах.
- Lenis: единый GSAP ticker, нативное поведение touch; диалоги исключены из сглаживания, anchors учитывают отступ.
- Кнопки: CSS, 150–200 мс, --ease-out cubic-bezier(.23,1,.32,1); hover-движение только для точного указателя.
- На ≤900 px закрепление снято; только небольшой параллакс иллюстрации. При reduced-motion отключены Lenis, GSAP, вступление и бесконечное движение эквалайзера.
- MatchMedia, ticker, события, аудиоконтекст освобождаются при размонтировании. Звук включается вручную и прекращается при уходе со вкладки.
