## Результат

- `npm run lint` — успешно.
- `npm run typecheck` — успешно; production build также выполняет TypeScript-проверку.
- `npm run build` — успешно, страница статически предварительно отрисована.
- 1440×1000, 768×1024, 390×844: изображения декодируются, горизонтальное переполнение отсутствует, консоль и HTTP-загрузки без ошибок.
- Все три диалога: открытие, название модели, спецификации, ссылка на официальный сайт; Tab удерживается внутри, Escape закрывает, фокус возвращается на исходную кнопку.
- Якорные переходы, кнопка коллекции, ручное включение/выключение аудио проверены.
- Возврат к началу проверяет восстановление прозрачности сцены и отсутствие внутренней прокрутки контейнера. `overflow: clip` предотвращает сдвиг иллюстрации при программном scrollIntoView.
- Reduced motion: на 1440 и 390 отключены сглаживание и длинная закреплённая сцена; проверено также изменение настройки во время работы страницы и повторная инициализация.
- Axe-core, WCAG 2 A/AA и WCAG 2.1 AA: 0 автоматических нарушений для страницы и трёх диалогов на 1440 и 390. Это не заменяет ручную проверку скринридером.
- Страница `/sources.html` доступна, источники, оригиналы и атрибуция указаны.
- `npm audit --omit=dev` — 0 уязвимостей production-зависимостей. Полный audit отмечает 5 advisory в цепочке dev-инструментов ESLint / fast-glob / micromatch / braces; принудительный downgrade конфигурации Next не применялся.

## Ограничения

Проверка выполнена в Chromium, без физических устройств, Safari и полноценного ручного прогона скринридером. Некоторые официальные товарные рендеры доступны только в 500×500; крупное фото COSMO и рисунок Yuki имеют более высокое исходное разрешение. Эмбиент синтезируется в Web Audio и не моделирует звучание конкретных наушников. Это локальный некоммерческий концепт с переходами на официальные страницы, без магазина и оплаты.
